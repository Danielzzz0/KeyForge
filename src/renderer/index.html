KeyForge help

1. Edit a mapping

Select an action, click its large input key, then press a keyboard key, mouse button, or mouse wheel direction. Advanced mode accepts raw RAGE input codes.

2. Use profiles

Create, rename, duplicate, or remove profiles from the left sidebar. Each profile keeps its own full mapping set.

3. Import and export

File → Open meta accepts .meta, .xml, .txt, and .html. Export a plain meta file or build an OpenIV .oiv package.

4. Keep a backup or share

File → Export default backup saves the original 210-mapping default; Build default .oiv package creates an OpenIV reset package. Share creates an offline code that another user can import as a new profile.
